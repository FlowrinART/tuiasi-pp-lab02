Problema 1
Codul prezentat realizează o aplicație Java care rulează un program in Python pentru a afișa toate cuvintele ce au aceeași sumă de control. Mai întâi se creează un context de execuție folosind platforma GraalVM, prin `Context.newBuilder().allowAllAccess(true).build()`, care permite aplicației Java să execute cod din alte limbaje. Programul Python este stocat într-un șir de caractere și conține logica principală: se importă `defaultdict` pentru a putea grupa ușor valorile, apoi se definește funcția `suma_control(v)` care calculează suma de control a unui cuvânt prin transformarea fiecărui caracter în cod ascii (folosind `ord`) și adunarea tuturor acestor valori. După aceea se definește un vector de cuvinte unde se face analiza, iar pentru fiecare cuvânt se calculează suma de control și se adaugă într-un dicționar unde cheia este suma, iar valoarea este vectorul de cuvinte care au aceeasi suma. Astfel, cuvintele care au aceeași valoare a sumei de control ajung în același vector. La final, programul parcurge toti vectorii și afișează doar acele cazuri în care există mai mult de un cuvânt asociat aceleiași sume de control. Ultima instrucțiune din Java, `context.eval("python", python)`, execută codul in Python în cadrul aplicației, iar rezultatele sunt afișate în consolă.


Problema 3
Acest program reprezintă o aplicație Polyglot, realizată cu ajutorul platformei GraalVM, care permite folosirea mai multor limbaje de programare în aceeași aplicație. Programul este scris în Java, dar folosește o funcție Python pentru citirea datelor de la tastatură. La început se creează un context de execuție care permite rularea codului Python în interiorul aplicației Java. În Python este definită funcția `citire()`, care citește două numere naturale: `n`, reprezentând numărul total de aruncări ale unei monede, și `x`, un număr din intervalul `1 ≤ x ≤ n`. Funcția verifică dacă valorile introduse sunt corecte, iar dacă nu sunt valide afișează un mesaj și oprește execuția. Dacă valorile sunt corecte, acestea sunt returnate către programul Java. După citirea valorilor, programul Java calculează probabilitatea de a obține "cel mult x apariții ale pajurii" în n aruncări de monedă, folosind distribuția binomială cu probabilitatea de succes `0.5`. Calculul se face în metoda `Bin`, unde pentru fiecare valoare de la `0` până la `x` se calculează probabilitatea folosind formula coeficientului binomial și se adună rezultatele. Pentru calculul coeficientului binomial este folosită funcția `factorial`, care determină factorialul unui număr. La final, probabilitatea obținută este afișată în consolă.
